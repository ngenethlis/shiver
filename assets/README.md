# Assets

Art used by shiver. Everything here is in use; unused concepts aren't kept in
the repository.

| File | What it is |
|---|---|
| `logo/shiver-icon.png` | The Signal Flame mark, 512×512 (app and notification icon) |
| `logo/shiver-icon-128.png` | The same mark, 128×128; compiled into the binary and used as the default notification icon (written to `~/.local/share/shiver/icons/shiver.png`) |
| `logo/banner.png` | Logo, wordmark and an example notification (README header) |

The Signal Flame logo was generated with Claude for this project (2026-11-18)
and chosen from a set of concepts. The icons are crops of the concept sheet.
