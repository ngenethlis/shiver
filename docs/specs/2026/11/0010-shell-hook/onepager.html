0010: Shell hook for failed commands

Created 2026-11-18 · done

Problem

The voices only speak on a timer or when asked. The moments that most call for an inner voice, like a build that just failed, pass in silence.

Proposal

One line in your shell config:

eval "$(shiver hook zsh)"     # in ~/.zshrc  (or: shiver hook bash, in ~/.bashrc)

After a command fails, shiver may show a notification with a line tagged fail. It runs in the background, so your prompt is never delayed.

To keep it from becoming noise:

  • Not every non-zero exit is a failure. Ctrl-C, Ctrl-Z and broken pipes are ignored, and so are commands where a non-zero exit is normal: grep, rg, diff, test, [, false, which.
  • At most one popup every 10 minutes from the hook (shiver hook zsh --min-gap 5m to change it).
  • fail lines only ever come from the hook or an explicit --tag fail, never from the timer.

The default pack gets a handful of new fail lines. Try it without waiting for a real failure: shiver on-fail --exit-code 1 --dry-run.

Scope

InOut (later)
  • shiver hook zsh|bash and shiver on-fail
  • Ignored exit codes and commands, rate limit
  • fail as a tag the timer never uses
  • fail lines in the default pack
  • Changing the ignore list (config file, 0011)
  • fish and other shells
  • Escalating lines for repeated failures
  • Success hooks (“the build finally passed”)

Decisions

ChoiceWhy
The shell snippet is tiny and calls shiver on-fail; all decisions happen in Rust. The rules are testable and identical across shells.
Rate limited by time, not by chance. A burst of failures gives one voice, not a pile of popups.
fail is a tag that's never active on its own. “That didn't work” makes no sense on a random timer popup.
bash reads the newest history entry at each prompt. bash has no pre-command hook. A DEBUG trap was tried first, but it also catches prompt commands and .bashrc lines, and it would replace other tools' traps. Commands kept out of history aren't seen.

Done when

  • Tests cover the ignore rules, the rate limit, the snippets (run in a real zsh and bash with a fake shiver), and on-fail --dry-run.
  • You've added the hook to your shell and seen a popup after a failing command.
  • All CI checks pass.
