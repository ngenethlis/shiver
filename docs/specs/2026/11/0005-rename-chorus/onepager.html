0005: Rename Library to Chorus

Created 2026-11-18 · done

Problem

In shiver-core, the file library.rs sits next to lib.rs, the crate's required entry point. The names look like duplicates, and “library” also means the Rust library crate itself, so “the library” is ambiguous in code and docs.

Proposal

Rename the type that holds every loaded voice and line from Library to Chorus: all the voices together. The file becomes chorus.rs. Behaviour doesn't change.

Scope

InOut

  • Any behaviour change

Decisions

ChoiceWhy
Rename the type, not just the file. The file should be named after what it holds, and with no users yet an API change costs nothing.
Chorus. Thematic: the set of all voices. Short and unlikely to clash.
Done specs aren't edited. They record what was built at the time; this spec explains the later change.

Done when

  • No Library or library identifiers remain in the code.
  • The same tests pass under their new names, and CI checks are clean.
